## 恢复、构建与发布

本目录是项目根目录。继续更新现有仓库，不需要重新新建仓库；恢复备份时复制项目目录内容（包括隐藏的 .github），不要上传外层备份目录。恢复前保留当前仓库备份，不覆盖尚未合并的更新。

GitHub仓库的 Settings → Pages → Source 应设为 GitHub Actions。GitHub Pages使用GitHub Actions发布，配置保存在 .github/workflows/pages.yml；26项JavaScript检查与两项Python检查通过后构建并部署。名字带旧版本号的检查脚本仍有效，不应按文件名删除。

本地构建需安装Node.js（支持import.meta.dirname的现代版本），在本目录运行：

```sh
node scripts/build-release.mjs
```

成品生成在 dist/，它是可重建产物，不纳入仓库。正式发布由工作流将提交编号作为 BUILD_VERSION 注入服务缓存；手动部署也应指定唯一 BUILD_VERSION。

图标母版及已生成PNG全部保留。只有重新生成图标时才需要sharp依赖；使用、测试和正常发布不需要重新生成图标。

## 学习数据与维护

个人数据存储在对应设备浏览器，不包含在仓库或网站文件备份中。换设备或清理浏览器前，请在网站设置中导出学习数据；不要清空数据来刷新网站。

首页“学习进度与备份”或设置中的“复制码迁移”：旧设备生成并复制，新设备粘贴、预览后导入。精简码含错题状态、收藏、掌握标签、待复核及逐题学习进度，不含完整考试历史、累计成绩、设置或未完成考试；完整迁移仍使用JSON文件备份。默认生成紧凑兼容码（SLQ1.C），不依赖CompressionStream/DecompressionStream；旧SLQ1.R和SLQ1.G仍可读，旧压缩码解不开时重新生成兼容码。接收设备须更新本站后再导入新码。内容过长时请使用文件备份，避免聊天软件截断。

默认合并收藏和待复核，掌握标签以迁入值为准，同题状态按时间选择，统计采用练习次数较多的一组而非相加。覆盖仅替换精简码涵盖的数据，导入前另有确认。复制码和完整文件导入都会先保存本机完整快照，可在迁移界面下载或撤销最近一次迁移；快照只保留一次，清理浏览器也会删除它。存储空间不足时拒绝迁移，不冒险覆盖原数据。

迁移码是携带学习数据的文本，不是加密密码，也不是短口令；勿公开分享。校验用于检查损坏，不能证明发送者身份。生成和解码不上传数据，需自行通过可信渠道传给新设备。

APP_VERSION只控制显示版本；store/session/bank结构版本分别为2/3/1。原题文字改动必须逐题对照原图，不能根据机器扫描或常识批量猜改。原图保留原样；保护校验检查题库封版哈希和111张图片的完整性。

首次联网后可离线使用核心题库；原图在实际查看后缓存。PWA安装依赖浏览器和系统权限及HTTPS环境，不能由网页强制创建图标；安装未完成会打开设备指引，可手选华为/鸿蒙、Android、iOS或电脑。没有桌面菜单的浏览器可改用支持安装的浏览器，或保留书签；换浏览器前先迁移数据。本地文件预览不等同于原网址的安装、缓存和学习数据环境。
