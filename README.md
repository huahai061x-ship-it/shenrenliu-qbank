## HOS题库内容与早期功能说明

507道原题、111张原图、标准填空104题、增强填空共208题（标准104 + 独立增强104），18道动态题共60个挖空变体。已统一修正19道原题的20项文字差异，并同步相关填空、答案、解析及旧题目快照；详见 [当前修订验收报告](v2.2.9原图文字修正验收报告.md)。

真实模拟 Ultra 固定45题：15单选、10多选、10判断、10填空。其中填空为3道基础单空、4道已核多空、3道概念要点。多空逐空录入，全对才计整题正确；无序集合用一对一匹配，重复词不能重复得分。旧55题考试入口从首页与快捷候选移除，历史成绩、未完成旧试卷和复盘保留。新增独立的概念释义与简答训练：先写再看参考答案，随后自行评为掌握、部分掌握或未掌握，未自评不计掌握率。专项背诵与专项模拟仍按单选、多选、判断或填空选择，原填空池仍为208题。默认快捷入口改为真实模拟 Ultra、今日复习、随机刷题、专项背诵，可自行编辑。

本次只启用修订包中已核原图的17条新候选：7条客观多空、9条反向概念和1条完整默写；其他9条候选没有启用。结构校验覆盖507原题、111张原图、208道原有填空和60个轮换变体，但不等于逐字目视核对。逐题诚实状态见 [v2.3逐题审计状态.json](v2.3逐题审计状态.json)：目前23道原题有原图核对依据，484道尚未逐题核对；208道旧填空的改写语义仍待逐题人工复核，不宣称全库OCR无误。

专项背诵默认逐题点击查看答案，可切换“答案一直显示”，偏好保存在当前浏览器。常显答案后作答不算独立答对。填空纯背诵只记录曝光，不伪造答题成绩。首页记住“所有训练模式”展开状态，包括返回和刷新；删除全库均衡复习入口，旧快捷项迁移为今日复习。错题本与收藏夹支持自选题量随机测试或全部测试，错题优先保留上次出错时的呈现快照；缺少快照时使用原题，全部测试保留各原题号。

所有训练模式中顺序背题紧跟随机刷题。错题本和收藏夹保留在首页重点入口，不再出现在所有训练模式及快捷候选中。复盘保留本场题型及挖空位置，也可切换原题对照。

首页透明头像“水豚噜噜”位于标题右侧，标题加大，左侧按标题和题库选择入口排列，紧凑居中且不遮挡头像。鼠标、触屏点击或键盘聚焦后按Enter/空格，都能进入学习小屋，查看学习记录与当前所选题库的掌握地图。这两项不再占用所有训练模式列表；已有自定义快捷项仍保留。角色气泡仅在首页出现，间隔22～36秒随机说一句，停留6.5秒后收起；离开首页或切后台会停止，不弹窗、不发声音、不联网、不修改学习数据。图片来自用户提供的头像，通过内置图片工具透明抠图并轻微清晰化，非重新设计角色。

## 恢复、构建与发布

本目录是项目根目录。继续更新现有仓库，不需要重新新建仓库；恢复备份时复制项目目录内容（包括隐藏的 .github），不要上传外层备份目录。恢复前保留当前仓库备份，不覆盖尚未合并的更新。

GitHub仓库的 Settings → Pages → Source 应设为 GitHub Actions。GitHub Pages使用GitHub Actions发布，配置保存在 .github/workflows/pages.yml；旧版回归、新版 Ultra 专项检查及题库数据检查通过后构建并部署。名字带旧版本号的检查脚本仍有效，不应按文件名删除。

本地构建需安装Node.js（支持import.meta.dirname的现代版本），在本目录运行：

```sh
node scripts/build-release.mjs
```

成品生成在 dist/，它是可重建产物，不纳入仓库。正式发布由工作流将提交编号作为 BUILD_VERSION 注入服务缓存；手动部署也应指定唯一 BUILD_VERSION。

图标母版及已生成PNG全部保留。只有重新生成图标时才需要sharp依赖；使用、测试和正常发布不需要重新生成图标。

## 学习数据与维护

个人数据存储在对应设备浏览器，不包含在仓库或网站文件备份中。换设备或清理浏览器前，请在网站设置中导出学习数据；不要清空数据来刷新网站。

首页“备份与换设备”和设置中的同名入口使用统一的TXT文件流程。旧精简迁移码代码仅保留给旧格式回归，不作为当前多库迁移入口。具体合并、覆盖和撤销行为见本页最新更新说明。

迁移码是携带学习数据的文本，不是加密密码，也不是短口令；勿公开分享。校验用于检查损坏，不能证明发送者身份。生成和解码不上传数据，需自行通过可信渠道传给新设备。

APP_VERSION只控制显示版本；store/session/bank结构版本分别为2/3/1。原题文字改动必须逐题对照原图，不能根据机器扫描或常识批量猜改。原图保留原样；保护校验检查题库封版哈希和111张图片的完整性。

首次联网后可离线使用核心题库；原图在实际查看后缓存。PWA安装依赖浏览器和系统权限及HTTPS环境，不能由网页强制创建图标；安装未完成会打开设备指引，可手选华为/鸿蒙、Android、iOS或电脑。没有桌面菜单的浏览器可改用支持安装的浏览器，或保留书签；换浏览器前先迁移数据。本地文件预览不等同于原网址的安装、缓存和学习数据环境。
