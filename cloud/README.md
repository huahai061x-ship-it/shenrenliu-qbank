# 邮箱登录与学习记录同步

正式站保留原GitHub Pages网址。顶部账户入口显示当前邮箱和同步状态；点击可打开账户面板。首次登录点“一键同步，开始学习”，先保存本机恢复副本，账号记录优先并补入本机独有项；逐项选择收在高级选项。未登录仍能使用本机题库及完整备份。

同步收藏、错题、掌握、学习和复核记录、成绩与原卷、累计统计、考试／练习／背诵恢复点、学习偏好及彩蛋记录。单库及混合范围分别保留最近两次恢复点。默认累计统计差异采用账号版本，高级模式可选择保留哪份，不将可能重复的统计直接相加；同份试卷的进度冲突可保存为独立副本。

答题或考试时暂缓接收云端变化，回首页再处理。断网变更留在本机；接收前先保存账号隔离的恢复副本，失败则不应用。应用回退可通过账户面板撤销最近一次接收；原TXT／JSON完整备份继续可用。不同人共用电脑需使用不同浏览器资料，避免本机记录混入另一账号。

## 正式与测试隔离

- 同一已购买环境：`shenrenliu-test-d3ftjonp001006b5`，上海；环境名称不代表正式数据使用测试集合。
- 正式函数：`shenrenliu-sync-prod`，Event类型，无公开HTTP入口，环境变量`QBANK_SYNC_SCOPE=production`。
- 正式集合：`qbank_prod_v1`、`qbank_prod_payload_v2`，均为`ADMINONLY`，只允许受控云函数访问；前者具有`owner_recordId`唯一复合索引。
- 原测试函数与集合保持独立；不迁移测试练习为正式成绩，不删除测试数据代替隔离。
- 身份只取云运行时SDK，不信任请求中的邮箱或用户ID。仅移除平台追加的`userInfo`和`tcbContext`，未知业务参数仍拒绝。
- 前端仅有公开环境标识；禁止将云密钥、SMTP密码或管理令牌写入配置和构建包。

客户端SDK锁定3.10.3，后端SDK锁定3.18.7。`npm ci --prefix cloud/client-sdk`后运行`node scripts/build-cloud-client.mjs`构建浏览器组件；`node scripts/prepare-cloud-sync.mjs`只准备后端包，不会发布函数。后端正式部署必须保留上述生产环境变量，不能仅替换函数名。

验证包括原生平台参数、无身份拒绝、事务并发冲突、分块完整性、账号隔离模拟、离线及恢复副本保护。真实手机的邮箱登录、收藏／错题及第3/507题恢复入口已在独立环境确认。模拟测试不等于全部真实设备和网络验收；正式站首次登录需本人收取验证码。

默认最多4个登录端，刷新令牌最长30天并自动刷新短令牌；服务端撤销、浏览器清理或第5个登录端可能使旧会话提前失效。验证码仍受原生邮件投递与60秒重发限制，组件减重不保证收件箱固定秒到。可见首页12秒轮询，回前台立即检查；题中不应用远端变化。已确认且本机未变的块不重复下载。
