# 访客模式与本机保存

新浏览器首次进入选择访客或邮箱。旧本机记录默认延续访客，已关联邮箱的用户保留账号恢复。访客不是CloudBase匿名身份，不创建云账号，不上传学习记录；升级邮箱沿用原来的本机副本与同步合并流程。

手机纵向卡片，电脑与平板横向卡片；320/390/430/768/1366像素截图分别验收。访客选择之前验证本机写入，显示本机模式而非宣称数据已经同步。

日常保存不重复存储网站自带题库，完整导出仍补齐题库。导入的自定义题库、学习记录、题号、恢复点均保留。保存失败展示明确提示，可从内存导出当前页面备份，无须先写入已经满了的存储。浏览器禁止存储或清除网站数据仍无法靠登录方式解决。
