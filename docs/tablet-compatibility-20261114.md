# 平板兼容与启动修复验收

用户环境：用户描述为“华为鸿蒙7自带的系统浏览器”，同时报告平板夸克无法保存。未取得真机远程连接、精确型号或内核版本，不能将用户问题唯一归因于某个 API，也不能宣布华为／夸克真机验收通过。

## 修改前复现

- 在独立浏览器禁用 `structuredClone` 后，练习正常显示，暂停保存返回 false；实际异常为 TypeError。禁用 `Object.hasOwn` 也能复现。原提示均将其归为存储不可用／空间不足。
- 挂起动态题库请求时，`#main` 始终为空；让 app.js 执行抛错时也出现只有顶部、主体空白。
- 桌面翻题侧栏已有 `pointer:fine` 条件，未发现它决定保存行为。触屏和平板尺寸属于不同测试维度，不能用桌面缩窗替代设备兼容测试。

## 修复

- 增加应用数据复制兼容实现，保留未作答值、数组、循环引用、二进制图片及独立副本；不替换浏览器全局实现。不支持的数据仍报错，避免静默丢失字段。同步标识继续使用安全随机数。
- 自有属性判断、数组尾项读取和文本替换使用更广泛支持的等价写法。
- 同步脚本改为有序 defer，保留依赖顺序，先显示加载与恢复面板。动态请求设 15 秒期限；静态模块停滞由 25 秒看门狗提示。主程序必须实际完成初始化。未选题库失败可继续当前库，所选题库缺失则停留恢复页，不自动改成其他库。
- 保存区分配额、访问限制、程序错误，提供可下载诊断（版本、阶段、错误类型／代码、脚本行列、浏览器能力；不采集账号、题目、作答）。完整练习／考试恢复点成功后才确认重试成功。
- 已有数据读取失败时停止写入。恢复页可下载原记录，故障注入检查导出与原始存储逐字节相同。

## 查证边界

- [MDN structuredClone](https://developer.mozilla.org/en-US/docs/Web/API/Window/structuredClone) 与 [Object.hasOwn](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/hasOwn) 说明 API 支持有版本差异；仅据此不能推定用户的实际内核版本。
- [华为 User-Agent 文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/web-default-useragent/) 提醒兼容标识可能包含其他操作系统名称。修复采用功能检测，不以 UA 或屏幕宽度猜测存储能力。
- 真正拒绝所有本机存储时不会宣称保存成功；仍需要保留本页、导出备份。大陆网络样本、发布批次以及真实设备确认分别记录，不混为一项验收。
