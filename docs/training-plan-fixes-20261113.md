# 训练与计划修正验收

## 范围和选择

沿用蓝白、圆角与现有两套设备布局。电脑翻题以完整页面标题定位，避免状态行定位后露出被裁切的标题底部；争议题的提示本身保留。手机翻题定位不变。

601px 以上的训练模式卡片采用纵向布局并将按钮推到卡片底部；计划列表也按同排高度对齐。手机双列卡片沿用原布局。不同屏幕分别检查，不用电脑截图代替手机验收。

用户手动标记已掌握后，计划默认跳过该题。可以在计划列表或详情勾选“包含已掌握题”，也可以将题目改回其他掌握状态。这个筛选偏好保存在本设备，题目掌握状态继续使用既有同步。筛选只作用于后续组题和预估日程，不删除原计划、事件、成绩、题目或已经暂停的队列。已完成任务仍计入每日用量。首次新题按原定日期逐步出现，不通过跳过已掌握题提前搬动日程。

答错后约10分钟再练是现有产品的间隔规则，不是对某位用户遗忘时间的判断。提示改为说明间隔再练，并在到期时自动刷新详情任务。离开详情不会被定时器拉回；刷新保持滚动位置。不改写原作答记录。

## 验收

- 学习计划核心测试新增：排除候选后再分配额度、全部排除、重新纳入、日程与队列一致、回忆记录保留、当天已做题仍占用每日额度。
- 浏览器检查 320、390、430、768、1366、1707px：卡片同排操作对齐、争议题标题完整、无横向溢出、已掌握默认排除与主动纳入、到期自动更新、离开详情不跳回。附加计划列表长标题场景与小屏计划截图。
- 既有训练浏览器检查通过：手机答题卡/焦点、宽度切换、考试暂停续练、严格交卷、计划范围与记录。
- 本地 70 项发布回归另存项目 outputs 下；发布后另核对本次版本和大陆运营商样本。样本检查不等于全部线路保证，浏览器尺寸模拟不等于微信/夸克真机验收。
