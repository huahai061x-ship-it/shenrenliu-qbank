# 训练可读性与计划操作

## 设计规格

场景为操作与阅读：连续答题应看得清、能直接选择，学习计划应记录真实作答，而不要求重复自评。
沿用已认可的柔和蓝白界面、圆角与噜噜，不增加装饰或新首页模块。沿用项目品牌色 #2563eb、正文 #172033、背景 #f5f7fb、面板 #ffffff、辅助文字 #687386，以及现有字体栈（Windows Microsoft YaHei / Segoe UI，移动设备 PingFang SC / 系统中文字体）。这些是现有产品约束，优先于通用视觉默认建议。

- 手机 ≤600px：原有文字尺寸与双列首页保持，计划批量控制换行，选项折叠入口至少44px高。
- 平板 601–1000px：保持侧边答题卡，正文18px、题干22px、选项18px，按可用宽度换行。
- 电脑 ≥1001px：正文18px、题干26px、选项20px、主要操作18px、辅助操作16px；容器仍1180px，两列答题区。间距以8px为基准，题干行高1.65。
- ≥1280px且精确指针：两侧页边距内设置淡蓝边框翻题按钮，宽度只取剩余空白，高180px。首页、弹窗、首末题不提供无效翻题动作，不代替底部导航。

## 行为与数据边界

计划首次及续练默认展示选项，可逐题收起/展开；不改变题型。移除重复的回忆自评和理解自评面板，保留掌握状态。提交按原答案判分，已有争议状态继续显示，判分不代表事实已核实。答对/答错/看答案后补对使用相同记忆安排；纯查看不伪造成答对。看答案后标记掌握，记录为辅助学习，不增加考试成绩。

每轮可选20/30/40/50，默认30，设备偏好独立保存，不更改计划结构、每日新题预算、账号同步格式和历史事件。已经有今日事件的计划显示继续今日计划。

本次用户明确要求争议题正常计分和安排复习，替代此前暂停判分的产品政策。原题、原答案、解析证据、稳定ID和旧记录保持；缺失有效答案的损坏数据仍不可判分。
