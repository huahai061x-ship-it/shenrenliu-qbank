# 答案解析验收规则（2026-10-20）

所有新增、导入或修改的单选、多选、判断题均执行此规则；填空题不受本次解析改写影响。

## 必须具备

- 单选、多选：具体考点 `topic`、选择依据 `why`、每一个原选项的具体理由 `optionReasons`。题目问错误项时，说明为何该项应被选中，不能把“选中”自动解释为内容正确。
- 判断：解释为什么对或具体错在哪里；错题必须有可成立的改正表述 `correction`。
- `status: "ready"` 代表已核准。新题库导入拒绝缺解析、未核准和含占位空话的题目。
- 不得以“不符合题目要求”“与正确答案不一致”代替概念、条件、数值、范围、步骤或因果分析。
- 理由必须绑定原选项文字，不绑定显示字母，以免乱序后错配。
- 命题范围内不选，不代表现实中永远为假；明确分类、岗位、时间与适用条件。
- 厂内日期、部门、数值仅说明原题口径。缺少现行制度时，不宣称已确认现行有效，更不得编造技术或法律依据。
- 结构检查只能拦截缺字段和明显空话，不能证明事实正确。发布者仍须逐题核对原始资料、答案、术语及例外。

新增题库示例：

```json
{"id":1,"type":"single","stem":"PDCA中C对应哪个阶段？","options":["检查","执行"],"answers":["检查"],"analysis":{"topic":"PDCA阶段含义","why":"C为Check，通过比较实际效果与目标检查措施是否有效。","optionReasons":{"检查":"检查阶段比较实绩与目标，识别差距。","执行":"执行对应D即Do，侧重落实计划中的措施。"},"status":"ready"}}
```
