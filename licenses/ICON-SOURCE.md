# 劉字图标来源

字形基于 LXGW WenKai Medium 的 U+5289（劉），已转换为 SVG 路径，不依赖终端字体。字体来源：https://github.com/lxgw/LxgwWenKai （fonts/TTF/LXGWWenKai-Medium.ttf，2026-09-27 获取）。授权正文见 LXGW-OFL.txt。

图标采用字体的自然书写轮廓，作独立标志的尺寸与视觉居中处理，不制作或分发衍生字体。背景为低饱和蓝靛紫渐变，字形最大边为画布的 62.5%，圆角为 21.875%。maskable 版本背景满版，前景再缩至 90%，确保完整落在中心 80% 安全圆内。

母版为 icon-source.svg。生成 scripts/generate-icons.cjs 所需依赖：Node.js 与 sharp。输出 16/32/48/64/128/192/256/512 PNG，以及 192/512 maskable。无需重新下载字体即可再生成。
